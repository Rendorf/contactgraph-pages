# ContactGraph appearance redesign — review guide

## How to open the concept

1. Open **More → Appearance & account** (or the existing Settings → Account screen).
2. Turn on **Preview the new design**.
3. Switch among Warm, Dark, Cyberpunk, Minimal, and System. Both choices are saved only on this device.

The preview can be disabled at any time to return to the legacy interface. No contact data or server preference is changed by previewing a design.

## Screens ready for review

- **Today:** a focused home screen for occasions, due follow-ups, today’s meeting journal, and what is coming next.
- **People:** the existing high-capability directory inside the new responsive shell.
- **Contact profile:** Profile, Timeline, and Edit are separated. Relationship status is qualitative; there is no hidden score.
- **Calendar:** meetings appear in the agenda only. They do not mark month-grid dates or increase attention counts.
- **Network:** the existing graph workspace is retained as a primary destination.
- **More:** meeting journal, follow-ups, data quality, canvases, OSINT, appearance, integrations, and role management are grouped by permission.
- **Mobile:** five-item bottom navigation with safe-area spacing; filters sit above it.

## Review questions

- Does Today show the right amount of information, or should any card become more/less prominent?
- Do Profile, Timeline, and Edit feel like the right separation for a person record?
- Is the Warm theme suitable as the default? Which regime should be used for screenshots and launch?
- Are the five primary destinations correct for daily use?
- Should the legacy interface remain available for one stable release after the redesign becomes default, as currently planned?

## Theme behavior

- **Warm:** calm paper-like surfaces and teal relationship accents.
- **Dark:** low-glare neutral dark surfaces.
- **Cyberpunk:** cyan/pink accents and monospace typography; no additional motion.
- **Minimal:** monochrome, tighter radii, and no decorative shadows.
- **System:** Warm when the operating system is light, Dark when it is dark.
